Comment ça marche

1

Télécharge et installe l'app (bouton "1." ci-dessus) — l'écran d'activation affiche ton "empreinte machine", un code unique à ton PC.

2

Copie ce code, puis clique sur "Acheter" — colle-le dans le champ "Empreinte machine" pendant le paiement Stripe (2,99 €, sécurisé).

3

Reçois ta clé de licence par email automatiquement, quelques secondes après le paiement.

4

Colle ta clé sur l'écran d'activation, et télécharge sans limite.

Questions fréquentes

La licence fonctionne sur combien de machines ?

Une licence = une machine. Si tu changes de PC, contacte-nous avec ta nouvelle empreinte pour une réactivation gratuite.

Je ne trouve pas mon empreinte machine, où est-elle ?

Elle s'affiche automatiquement à l'ouverture de l'app, sur l'écran d'activation, avant même de payer — installe l'app d'abord si besoin.

C'est compatible Mac / Linux ?

Non, Maderino Downloader est disponible pour Windows uniquement pour le moment.
