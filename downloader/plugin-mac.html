macOS · v1.0.8

Le plugin Premiere Pro, version Mac

Apple Silicon et Intel. Pas encore d'installeur packagé : une seule commande Terminal fait tout le travail.

🧪

Version bêta

Le portage Mac est récent et pas encore éprouvé à grande échelle : installation manuelle (pas de vrai installeur pour l'instant), et certaines fonctions n'ont été testées que sur peu de configurations. Ça fonctionne, mais signale-nous le moindre souci.

Colle ça dans Terminal, puis Entrée

terminal — zsh
mkdir -p ~/Library/"Application Support"/Adobe/CEP/extensions/com.maderino.premiere.downloader && \
curl -L -o /tmp/maderino-plugin.zip "https://github.com/maderino-prod/maderino-downloader/releases/download/plugin-v1.0.8/Maderino.Downloader.Plugin_v1.0.8.zip" && \
unzip -oq /tmp/maderino-plugin.zip -d ~/Library/"Application Support"/Adobe/CEP/extensions/com.maderino.premiere.downloader && \
rm /tmp/maderino-plugin.zip && \
# autorise Premiere a charger une extension non signee
for v in 9 10 11 12; do defaults write com.adobe.CSXS.$v PlayerDebugMode 1; done && \
echo "Installe. Ouvre (ou redemarre) Premiere Pro, puis Window > Extensions > Maderino Downloader."

Ensuite : ouvre (ou redémarre) Premiere Pro, puis Window → Extensions → Maderino Downloader.

Le panneau demande l'activation — même licence que l'app Windows, liée à une empreinte machine différente : contacte-nous si besoin d'une réactivation.

Méthode manuelle (si le Terminal échoue)

1

Autorise les extensions non signées : dans Terminal, defaults write com.adobe.CSXS.9 PlayerDebugMode 1 (répète pour .10, .11, .12).

2

Télécharge et extrais Maderino.Downloader.Plugin_v1.0.8.zip (double-clic dans Finder).

3

Crée le dossier ~/Library/Application Support/Adobe/CEP/extensions/com.maderino.premiere.downloader/ (Finder : Cmd+Shift+G).

4

Copie les cinq dossiers extraits (CSXS, bin, frontend, js, jsx) directement à l'intérieur.

5

Ouvre Premiere Pro → Window → Extensions → Maderino Downloader.

Questions fréquentes

Les mises à jour suivantes se passent comment ?

Automatiquement, depuis le panneau — la commande Terminal ne sert qu'à la toute première installation. Une bannière apparaît quand une nouvelle version sort, exactement comme sur Windows.

Pourquoi pas un vrai installeur ?

Il arrivera. En attendant, cette méthode installe exactement les mêmes fichiers, au même endroit.
